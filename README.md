# hobbyl

Карта хобби Киева: занятия на карте, фильтр по времени и цене, запись, режим ведущего. Язык сайта — украинский.

## Запуск (VS Code)

Нужен Node.js 20.9 или новее (лучше 22, см. `.nvmrc`).

```bash
git clone https://github.com/olejanikopol-cmd/hobby.git
```

```bash
cd hobby
```

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:3000. VS Code при открытии папки предложит расширения ESLint и Tailwind CSS — их стоит поставить.

| Команда | Что делает |
|---|---|
| `npm run dev` | сайт для разработки, изменения видны сразу |
| `npm run build` и `npm start` | боевая сборка и её запуск |
| `npm test` | юнит-тесты (время по Киеву, очистка HTML, стиль карты) |
| `npm run check` | всё сразу: типы, линтер, тесты, сборка |

## Демо-режим

Базы данных пока нет. Занятия и ведущие лежат в `src/data/`, а всё, что делает пользователь (вход, записи, избранное, свои занятия, сообщения), хранится в браузере (localStorage). Вход демонстрационный: подходит любой email и любой 6-значный код. Сбросить данные: «Мій кабінет» → «Налаштування» → «Видалити мої дані».

## Интернет

Подложка карты (OpenFreeMap), спутник (EOX Sentinel‑2) и шрифты карты грузятся из интернета. Без сети сайт работает, но карта будет пустой, с пинами занятий.

## Структура

```
src/app/         страницы (Next.js App Router)
src/components/  компоненты: карта, фильтры, страница занятия, кабинет, редактор
src/lib/         логика: время по Киеву, store (демо-данные), очистка HTML, стиль карты, .ics
src/data/        каталог категорий (29 / 338), демо-занятия и ведущие
scripts/         копирование воркера MapLibre в public/ (запускается само)
design/          дизайн-макеты (Claude Design)
docs/            архитектура, UX-ревью, правила кода
```

Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), правила кода: [docs/RULES.md](docs/RULES.md).
