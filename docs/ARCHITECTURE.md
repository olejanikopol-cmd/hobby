# hobbyl — архитектура (v0.2)

28.10.2026, обновлено после сборки демо-версии. Автор: Claude (архитектор). Читают: владелец проекта, DeepSeek (исполнитель), Codex (ревью).
Дизайн: https://claude.ai/artifact/6evZD6opGAHayF1r5E46Yq (10 экранов).

## 1. Что строим

Сайт-карта хобби Киева. Человек видит на карте занятия, фильтрует по времени и цене, записывается.
Любой пользователь может стать ведущим и опубликовать своё занятие.

Решения, уже принятые владельцем:
- язык сайта — украинский; город — Киев;
- цвета — зелёный `#2F6B4F` + белый; стиль тёплый;
- шрифты — Unbounded 800 (логотип), Golos Text 800 (заголовки), Comfortaa (волнистые акценты), Onest (текст);
- раскладка — список + карта; телефон и компьютер одинаково важны;
- фильтр времени: Зараз · Сьогодні · Завтра · Вихідні · Тиждень · Завжди · дата;
- один аккаунт для всех, кнопка «Стати ведучим»;
- запись без онлайн-оплаты: платят ведущему на месте;
- вход: Google, код на email, Telegram;
- карта: MapLibre + OpenFreeMap.

## 2. Технологии (стек — набор технологий)

| Часть | Выбор | Почему | Альтернатива |
|---|---|---|---|
| Сайт и сервер | Next.js + TypeScript | Самый частый стек в обучении ИИ: DeepSeek и Codex ошибаются реже. Страницы занятий видны в Google (SEO). | SvelteKit — легче, но примеров меньше |
| Стили | Tailwind CSS | Цвета и шрифты задаются один раз в настройках | обычный CSS |
| База данных, вход, файлы | Supabase (Postgres + PostGIS + Auth + Storage) | Всё в одном месте, есть бесплатный тариф, PostGIS ищет «что рядом» | Firebase — слабее для поиска по карте |
| Карта | MapLibre GL JS + OpenFreeMap | Бесплатно, без ключа. Стиль `positron`, перекрашенный в палитру hobbyl; слои Схема · Ніч · Супутник и 3D-здания | Mapbox, Google Maps — нужны ключ и карта оплаты |
| Спутник | EOX Sentinel‑2 cloudless 2016 | Бесплатно, лицензия CC BY 4.0 (нужна подпись). Выпуски 2018+ — только некоммерческие | Esri, Mapbox Satellite — платно при трафике |
| Шрифты | `@fontsource/*` (свои файлы) | Сборка не зависит от сети и от Google | `next/font/google` |
| Хостинг | Vercel | Деплой (выкладка) из GitHub одной кнопкой | Cloudflare Pages |
| Письма с кодом | Supabase Auth, позже Resend | Встроено | — |
| Тесты | Vitest (логика) + Playwright (сценарии в браузере) | Стандарт для Next.js | — |

Проверить перед запуском (не проверено):
- лимиты бесплатного тарифа Supabase: бесплатный проект засыпает без активности;
- правила Vercel: бесплатный тариф — для некоммерческих проектов. Когда появятся деньги, нужен платный;
- правила OpenFreeMap: на что можно рассчитывать при большом трафике.

## 4. Данные (таблицы в базе)

```
profiles      id, name, avatar_url, bio, district, interests[], is_host, slug, telegram_id, instagram
categories    id, parent_id, slug, name_uk, color, icon, sort   ← 2 уровня: категория → направление
places        id, host_id, title, district, location_public (точка, уже сдвинутая ~200 м)
places_private place_id, address_text, location     ← точный адрес отдельно, см. раздел 6
activities    id, slug (уникальный, для /a/[slug]), host_id, place_id, category_id, kind, title,
              description_html, photos[], price_type, price_uah, price_unit, capacity, age_min,
              status, audience[], cover_color   ← category_id = направление (нижний уровень)
schedules     activity_id, rule (повтор: «пн/ср/пт 19:00»), starts_on, ends_on
sessions      id, activity_id, starts_at, ends_at, status        ← конкретные даты занятий
bookings      id, session_id, user_id, status, created_at        ← unique (session_id, user_id)
favorites     user_id, activity_id
follows       user_id, host_id
reports       id, activity_id, user_id, reason                   ← жалобы для модерации
```

Значения полей:
- `kind` (формат): `masterclass` · `section` · `course` · `club` · `lecture` · `workshop` · `circle` (коло) · `support_group` · `retreat` · `tournament` · `excursion` · `trial` · `individual`;
- `audience[]`: `adults` · `kids` · `teens` · `couples` · `families` · `seniors` (60+) · `veterans` · `inclusive` · `beginners`;
- `price_type`: `paid` · `free` · `donate`;
- `price_unit`: `per_visit` · `per_month` · `per_course`;
- `status` у занятия: `draft` · `published` · `hidden`;
- `status` у записи: `booked` · `cancelled` · `attended` · `no_show`.

- `description_html`: текст ведущего с форматированием отдельных слов (жирный, курсив, зачёркнутый, цвет, маркер, «хвилястий», заголовок, списки, ссылки). Видео нет. Перед сохранением и перед показом HTML проходит белый список тегов (`src/lib/sanitize.ts`).

Каталог категорий — `src/data/categories.json`: 29 категорий, 338 направлений, форматы и аудитории. Это сид (начальные данные) для таблицы `categories`. Ведущий может предложить новое направление — оно попадает на модерацию.

Регулярные занятия: правило хранится в `schedules`. Ежедневная задача по расписанию (cron в Supabase) создаёт `sessions` на 8 недель вперёд — без неё через 8 недель карта опустеет.

## 5. Логика фильтра времени

Часовой пояс всегда `Europe/Kyiv`.

| Кнопка | Что показываем |
|---|---|
| Зараз | `sessions`, которые идут сейчас или начнутся в ближайшие 2 часа |
| Сьогодні | `sessions` с текущего момента до полуночи (прошедшие не показываем) |
| Завтра | `sessions` на завтрашнюю дату |
| Вихідні | ближайшие суббота и воскресенье; если сегодня выходной — с сейчас до понедельника |
| Тиждень | `sessions` с сейчас до +7 дней |
| Завжди | занятия с регулярным расписанием (`schedules`), без привязки к дате |
| 📅 дата | `sessions` на выбранную дату, не раньше текущего момента |

Если пользователь не выбрал время, а на сегодня всё закончилось (поздний вечер), карта показывает «Тиждень» и пишет об этом.
Реализация — `src/lib/time.ts`, тесты — `src/lib/time.test.ts` (включая переход на летнее/зимнее время и занятия после полуночи).

## 6. Безопасность и приватность

- RLS (Row Level Security — правила доступа к строкам базы):
  - опубликованные занятия читают все;
  - менять занятие может только его ведущий;
  - запись видят сам участник и ведущий этого занятия.
- Точный адрес студии видят только записавшиеся. Остальным карта показывает точку со сдвигом ~200 м и район.
  RLS прячет строки, а не столбцы, поэтому адрес лежит в отдельной таблице `places_private` (читает ведущий и тот, у кого есть запись), а сдвинутая точка вычисляется один раз при сохранении. Если сдвигать на каждый запрос, точный адрес можно вычислить усреднением.
- Запись — только через функцию базы `book_session(session_id)`: в одной транзакции блокирует сессию, сверяет число записей с `capacity` и вставляет запись. Иначе два человека одновременно займут последнее место.
- Ключи (секреты) только в переменных окружения. В коде ключей нет. Ключ service-role Supabase — только на сервере, никогда не с префиксом `NEXT_PUBLIC_`.
- HTML ведущего — только после очистки белым списком (`sanitizeHtml`); ссылки получают `rel="noopener noreferrer nofollow"`.
- Параметр `?next=` после входа принимает только внутренние пути (`safeNext`), иначе это открытый редирект.
- Перед запуском: `/security-review` и политика конфиденциальности (закон Украины о персональных данных).

## 9. Нюансы, о которых важно помнить

- **Пустая карта на старте.** Без занятий сайт бесполезен. До запуска вручную заполнить 30–50 реальных занятий с согласия ведущих. Это главный риск проекта, не код.
- **Записались и не пришли.** Напоминание за 3 часа; ведущий отмечает «не прийшов».
- **Ведущий отменил занятие.** Всем записавшимся — уведомление.
- **Переход на зимнее/летнее время.** Регулярные занятия хранить в местном времени Киева.
- **Модерация.** Новые занятия публикуются сразу, но есть кнопка «Поскаржитися» и скрытие админом.
- **Instagram.** У каждого занятия красивая картинка-превью для ссылок (OG-картинка).

## 12. Ошибки архитектуры, найденные при сборке демо-версии

| Было | Почему ошибка | Как исправлено |
|---|---|---|
| У `activities` не было `slug` | адрес `/a/[slug]` не из чего строить | добавлен уникальный `slug`, транслитерация с украинского (`slugify`) |
| `exact_address_private` — столбец в `places` | RLS не прячет отдельный столбец: адрес видели бы все | отдельная таблица `places_private` |
| Сдвиг точки ~200 м «при показе» | новый случайный сдвиг на каждый запрос выдаёт точный адрес усреднением | сдвиг считается один раз и хранится |
| Запись — обычная вставка в `bookings` | гонка: два человека занимают последнее место | функция `book_session` + unique (session_id, user_id) |
| `page_blocks` с видео | владелец отказался от видео; блоки не дают форматировать отдельные слова | `description_html` + редактор + белый список тегов |
| «Сьогодні» = вся дата | утром видно уже прошедшие занятия | с текущего момента до полуночи; поздно вечером — автоматически «Тиждень» |
| «Вихідні» не определены для субботы и воскресенья | в воскресенье показывались бы следующие выходные | если сегодня выходной — с сейчас до понедельника |
| Сессии «создаются заранее» без механизма | через 8 недель карта пустеет | ежедневный cron |
| Шрифты через `next/font/google` | сборка падает без сети (CI, VPN, блокировки) | `@fontsource/*` |
| MapLibre «просто подключить» | Next.js не кладёт в сборку воркер MapLibre — карта не рисует тайлы | `scripts/copy-maplibre-worker.mjs` копирует воркер в `public/` при `install`/`dev`/`build`, карта вызывает `setWorkerUrl` |
| Контейнер карты с классом `absolute` | CSS MapLibre вне слоёв Tailwind перебивает `absolute` на `relative`, высота карты становится 0 | контейнер карты внутри отдельной абсолютной обёртки |
| Время — «по Киеву» без механизма | серверы Vercel работают в UTC | все расчёты через `Intl` с `Europe/Kyiv` (`src/lib/time.ts`), тесты на переход времени |

## 13. Демо-режим и переход на Supabase

Сейчас база не подключена: занятия и ведущие — `src/data/*.ts`, действия пользователя — `localStorage` (`src/lib/store.ts`, ключ `hobbyl:v1`). Вход демонстрационный.

Переход на Supabase меняет только `src/lib/store.ts` и источники данных: компоненты читают данные через `useActivities()`, `useAppState()` и `actions.*`. Порядок: таблицы и RLS → чтение занятий → вход → запись через `book_session` → режим ведущего.
